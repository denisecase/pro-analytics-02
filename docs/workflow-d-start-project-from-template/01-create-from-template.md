# 🟡 Start in GitHub to Create a New Project From Template

1. Log in to GitHub. Open your browser and log in to your GitHub account.

2. Open the Provided Project Template

   - Navigate to the GitHub repository provided as the project template.
   - Click the **Use this template** button.
   - Select **Create a new repository**.

3. Name Your Repository

   - Enter a name for your new repository.
   - IMPORTANT: Follow naming guidelines for Python Projects:
     - Use all lowercase.
     - Use dashes between words.
     - NEVER USE spaces or special characters.
     - Good Examples: my-python-project, python-experiments, baseball-stats,
        python-personal-project, website-analytics, student-impact-analysis

4. Provide a brief description of your project. This is optional but recommended.

5. Select the `Public` option so others can view your repository.
   You may always use a fake name or alias.

6. Review the Repository Settings

   - Verify that you are creating a **new repository from the provided template**.
   - The template already includes the project files and scaffolding needed for the remaining steps.
   - Do not create a separate empty repository first.

7. Click the `Create repository` button to finalize the process
   and create your new repository in GitHub.

## IMPORTANT

- Start with the correct template.
