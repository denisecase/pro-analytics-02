# 🟡 Workflow D: Start Project From Template

> Start a new professional Python project from a template.

The easiest and most reliable way to start your own professional Python project
is from a prepared template.
Create a new repository from the template,
clone your new repository to your machine, then
inspect and customize the provided scaffolding for your project.

<details markdown>
<summary>WHY?</summary>

A project template provides a consistent professional starting point
while allowing you to focus on your own custom project.

Because the project structure and tooling are already in place,
you can inspect and customize the configuration (and all the associated decisions)
rather than designing and building the project infrastructure from scratch.

Using a template to start a custom project is
a great way to stay current and
showcase your technical skills and professional communication.

</details>
