# 🟣 Run the Project

Professional practice is to run, check, and test code regularly as changes are made.

Your project environment was set up during Workflow C.

Ensure only the **project repository folder** is open in VS Code.

You may already have a VS Code terminal open. If not,
open a VS Code terminal (e.g., using the VS Code menu
**Terminal / New Terminal**).
The terminal should open in the root project folder.

## Step 1. Run the Project Code

Find the exact command to run the project in the **project README.md**.
In the VS Code terminal,
copy and paste that command, then hit ENTER or RETURN.

For example:

```shell
uv run python -m datafun.app
```

The package and module names may differ by project.
Use the command provided in your project's README.md.

For more information, see
[Running Python Projects Reliably](../reference/python/running-python.md).

## Step 2. Verify the Results

Review what happened when the project ran.

- Check the terminal for errors and expected success messages.
- Review any output files, logs, or visualizations.
- Confirm the results are consistent with the project README.md.
- If visualizations open in separate windows, close them as needed to allow the program to finish.

If the project does not run successfully,
review the error messages and investigate before continuing.

## Verification

- [ ] My project runs without errors.
- [ ] The expected output and/or success message appears.
- [ ] Expected results and visualizations are produced.
- [ ] I can explain what the project does and what the results show.

## Professional Recommendations and Reminders

- Enable **File / Auto Save** in VS Code or save changes regularly.
- Use logging and debugging statements to investigate errors.
- Review results and resolve unexpected errors before committing changes.
