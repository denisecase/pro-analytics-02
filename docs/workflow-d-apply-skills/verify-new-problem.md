# 🟣 Run and Verify the New Problem

> Confirm the project runs end to end on the new data.

## Step 1. Run End to End

Run the whole project, not just part of it.
See [Run Your Project](run-project.md).

## Step 2. Confirm the Results Answer the New Problem

Files left over from the example can look like new output.
Confirm that:

- output files and visuals were created or updated by this run
- the results address the new problem, not the example's
- names, labels, and counts match the data used
- titles, labels, and units in visuals describe the new problem

## Step 3. Check the Repository State

```shell
git status
```

Confirm the changed files are the ones expected,
and that no environment folders, caches, or other generated files
are about to be added.

## Verification

- [ ] The project runs from start to finish without errors.
- [ ] The outputs address the new problem.
- [ ] Visual titles and labels describe the new problem.
- [ ] `git status` lists only expected files.
