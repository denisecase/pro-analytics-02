# 🟠 Workflow C: Start New Custom Project

<!-- On a page that could be read aloud,
use two asterisks instead of backticks
for code. -->

> Start your own project based on the example.

Your new project will have its own GitHub repository,
Git history, code, and documentation.

<details markdown>
<summary>WHY?</summary>

Professional work often involves learning from existing projects
and applying proven techniques to new problems.

This workflow develops the ability to understand an example,
and use that example to create a new project that you
can experiment with and use to solve new problems.

</details>

## Review and Take Ownership of the Project Code

After making your first git add-commit-push,
review the important project code files, understand their purpose,
and customize the heading of each source file
to indicate that this project will hold **your** custom work.

1. [Review project configuration](create-pyproject.md)
2. [Set up Environment (managed by uv)](manage-environment.md)
3. [Install and Run Git Hooks](git-hooks.md)
4. [Take Ownership of Code Files](customize-code-files.md)
5. [⭐Git Add-Commit-Push to GitHub](git-add-commit-push.md)

---

## Success

This workflow is complete when you can:

1. Provide a clickable link to your custom GitHub repository.
2. Open your custom project in VS Code.
3. Explain the purpose of the main project files and folders.
4. Identify and explain your project-specific configuration changes.
5. Set up the Python environment and run the project checks.
6. Commit and push your changes to your custom GitHub repository.
