# 🟠 Draft README.md

> Write an initial version of the README so the repository has a clear starting point.

## Previously

This assumes the problem and data were chosen,
the repository was created on GitHub and cloned,
and the project is open in VS Code (`code .`).

## Step 1. Open README.md

If GitHub created a **README.md** with the repository,
it appears in the VS Code Explorer.
If not, create **README.md** in the repository root.

## Step 2. Write the Draft

The draft includes:

- the project title
- your name or alias
- year and month
- an overview of one or two sentences:
  the problem and the data
- a **Commands** heading (the commands are added once the project runs)
- a **Links** section with the example project you are adapting
  and your data source

Use this structure:

```markdown
# Project Title

Your Name or Alias
YYYY-MM

## Overview

One or two sentences: the problem and the data.

## Commands

Commands to set up and run the project are added after the project runs.

## Links

- Include a link to the example project and/or other resources.
- Include a link to the project data-card.md.
```

## Step 3. Preview

Open the Markdown preview in VS Code:

- Windows/Linux: `Ctrl + Shift + V`
- macOS: `Cmd + Shift + V`

Confirm the headings and links display as intended.

This is a draft.
The README is updated as the project develops and reviewed at the
end of the project to ensure it is complete and useful.

## Verification

- [ ] README.md is saved in the repository root.
- [ ] README.md includes the name or alias, year and month, and an overview.
- [ ] The overview names the problem and the data.
- [ ] The links credit the example and the data source.
- [ ] The text is written for this project and not copied from the example.
