# 🔴 Update Project README

> Make README.md the landing page for the finished project.

## Previously

This assumes README.md was drafted in Phase 1
and docs/index.md has been updated with the story.

The README is the first page a visitor sees.
Keep it short and point to the docs for the full story.

## Step 1. Open README.md

Open **README.md** in VS Code.

## Step 2. Update the Required Items

The README includes:

- your name or alias
- year and month
- Project Overview: what the project does and which problem was chosen
- Project Commands: how to set up and run the project
- at least one visual with evidence confirming the work
- common links at the end
- optional: badges

Update the overview if the problem or data changed during the project.

## Step 3. Write the Commands

List the commands as they were run, in order.
Copy them from what actually worked.

Then follow them as written, in a new terminal opened in the repository root,
to confirm they work.

## Step 4. Add a Visual

Use a visual saved in the repository,
for example the one used in docs/index.md.
Reference it with a path relative to README.md:

```markdown
![Description of what the visual shows](docs/images/your-visual.png)
```

## Step 5. Update the Links

The links at the end include:

- the project documentation site
- the example project that was adapted
- the data source

## Step 6. Optional Badges

Badges report live status from GitHub.
For example, a badge for a workflow:

```markdown
![Workflow status](https://github.com/youraccount/your-repo/actions/workflows/your-workflow.yml/badge.svg)
```

Do not type facts that can go stale (such as version numbers)
into the README.
Use a badge that reports them instead.

## Step 7. Preview

Open the Markdown preview in VS Code:

- Windows/Linux: `Ctrl + Shift + V`
- macOS: `Cmd + Shift + V`

After the push, open the repository on GitHub and confirm
the visual displays and the links open.

## Verification

- [ ] README.md includes the name or alias, year and month, and an overview.
- [ ] The commands are listed and work when followed as written.
- [ ] README.md includes a visual that displays.
- [ ] The links to the docs, the example, and the data source open.
- [ ] No text from the example remains that does not describe this project.
